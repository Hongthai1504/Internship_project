# 🎨 BestTech Brand & Design System

## 1. Brand Identity
- **Brand Name:** BestTech
- **Slogan:** "Top Tier Technology, Transparent Experience."
- **Positioning:** A premium, tech-focused e-commerce platform offering deep specification comparisons and seamless user experiences.

## 2. Visual Style: Glassmorphism
The platform utilizes **Glassmorphism** as its core visual language to convey a modern, clean, and high-tech feel.
- **Key Characteristics:** 
  - Semi-transparent backgrounds (`rgba(255, 255, 255, 0.85)`).
  - Background blur (`backdrop-filter: blur(12px)`).
  - Soft, pastel underlying colors.
  - Floating layouts with gentle shadows (`box-shadow: 0 10px 40px rgba(0,0,0,0.04)`).
  - Rounded, friendly geometry (border-radius from `12px` to `24px`).

## 3. Color Palette
Consistent use of color is critical for our UI/UX.

| Color | Hex Code | Usage |
| :--- | :--- | :--- |
| **Primary (Brand)** | `#0046be` | Main buttons, active states, page titles, primary links. |
| **Primary Dark** | `#001e50` | Gradients, hover states for primary elements. |
| **Background** | `#f4f7fb` | Main body background (pastel/soft gray-blue). |
| **Text Main** | `#0f172a` | Primary headings and important body text. |
| **Text Muted** | `#64748b` | Secondary text, labels, empty states. |
| **Success** | `#10b981` | Completed orders, success messages, in-stock alerts. |
| **Danger/Warning**| `#ef4444` | Cancelled orders, delete actions, out-of-stock alerts. |

## 4. Typography
- **Primary Font Family:** `Nunito`, sans-serif.
- **Font Weights:**
  - `Regular (400)`: Body text, descriptions.
  - `Semi-Bold (600)`: Sub-headings, table headers, secondary buttons.
  - `Extra-Bold (800)`: Primary buttons, card titles, navigation links.
  - `Black (900)`: Main page titles, price tags, critical numbers.

## 5. Tone of Voice & UX Writing
- **Professional yet approachable:** The system communicates clearly without overly robotic jargon (e.g., using "Welcome back!" instead of "Authentication successful").
- **Bilingual Support (i18n):** All UI strings are supported in both English (US) and Vietnamese (VI) to accommodate local and international users.
- **AI Persona:** The integrated Groq/LLaMA 3 assistant acts as a concise, expert tech reviewer.
